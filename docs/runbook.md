# Эксплуатация

## Штатная публикация

Проверьте результат Pylint, выполните слияние и дождитесь заданий build и deploy. Откройте URL окружения github-pages и проверьте маркер версии.

## Ручной запуск

В Actions выберите Publish documentation → Run workflow.

## Диагностика

Определите отказавший этап и изучите журнал его шагов. Сопоставьте опубликованную версию и SHA запуска.
