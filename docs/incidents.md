# Журнал типовых инцидентов

| Инцидент | Признак | Где проверить |
| --- | --- | --- |
| Неиспользуемая переменная | W0612 | Static analysis |
| Недостаточные права | Сборка прошла, публикация упала | Deploy to GitHub Pages |
| Битая ссылка | Строгая сборка завершилась ошибкой | Build documentation |
| Устаревший сайт | В браузере прежняя версия | URL окружения, SHA, кэш |

Для разбора фиксируйте симптом, журнал, причину, исправление и результат проверки.
